# Book Store

This is a simple book store application built using the MERN stack (MongoDB, Express, React, Node.js). The application allows users to browse products, add them to a shopping cart or wishlist, and view all available books on the homepage.

## Features

- View all available products on the homepage
- Add books to the shopping cart
- Add books to the wishlist
- View and manage the shopping cart and wishlist

## Technologies Used

- **MongoDB**: NoSQL database to store book details.
- **Express.js**: Web framework for building the backend API.
- **React.js**: Frontend library for building the user interface.
- **Node.js**: JavaScript runtime to run the server.
